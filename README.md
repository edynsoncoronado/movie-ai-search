# Movie AI Search

AI-powered movie search API: ask in natural language (*"movies like Star Wars where the dog doesn't die"*) and get relevant movies with grounded explanations.

**Status:** 🚧 in progress, part of my 100-day challenge. Built with Spec-Driven Development + TDD.

Planned: hybrid search (vectors + keywords) with RRF, LLM query understanding with structured outputs, RAG answers with citations, and an evaluation set with nDCG@k / recall@k.

Data: see [`data/README.md`](data/README.md).
